# Interactive Workplace Shell

The shell is a workplace frame, not an LMS dashboard.

Primary navigation:
Today | Work | People | Messages | Meetings | Files | Systems | Support

## Today
Today is a briefing. It answers:
- what changed;
- what is next;
- what needs attention;
- what is waiting on someone else.

It should not show learning percentages, badges, XP, course cards or generic KPI tiles.

## Authorization
Every surface is resolved from the authenticated employee principal. Navigation visibility is not security; server authorization still applies to each request/action.

## Systems
Professional systems remain contextual. The Systems surface may show authorized environments and recent systems, but should not become a vendor-logo catalog.

## Responsive behavior
Desktop may use persistent navigation. Small screens should use a compact workplace menu while preserving the same information architecture and 44px minimum interactive targets.

## Accessibility
- skip link;
- semantic navigation/main landmarks;
- visible focus;
- aria-live for changed workday briefing where useful;
- keyboard access;
- captions/text alternatives for meetings;
- no critical information encoded only by color or motion.
