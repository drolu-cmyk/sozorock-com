# Interactive Messages, Meetings and Work

## Messages
Messages are threaded workplace communication. Replies remain attached to the work context and become professional evidence only when substantively relevant.

## Meetings
Meetings show upcoming and past sessions. Voice, text and captions remain equivalent supported modes. Meeting entry should preserve the same work context and participant identity.

## Work detail
A work item is the center of professional activity. The detail surface can show:
- matter/request title and status;
- deadline;
- evidence gathered so far;
- what the employee is waiting on;
- contextual professional systems;
- artifacts already created;
- actions available for the current work type.

## Waiting
Waiting is a first-class workplace state. If an employee is waiting for a manager, requestor or system owner, the matter should visibly reflect that rather than pretending all work is immediately actionable.

## Evidence
Evidence appears as an attached work panel, not as a score. It should clearly distinguish source, observation and timestamp.

## Artifact submission
Professional deliverables are submitted as workplace artifacts. Submission is a meaningful event and may enter assessor or manager review.
