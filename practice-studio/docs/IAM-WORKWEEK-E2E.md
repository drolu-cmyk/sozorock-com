# IAM Workweek End-to-End Acceptance

## Purpose
Prove that Practice Studio can run a coherent professional episode across workplace time, people, tools, evidence, consequences and debriefing.

## Included flow
1. Employee enters the workday under their registered identity.
2. Manager welcome and team meeting occur on the workplace calendar.
3. Required training and ordinary work exist before any incident.
4. An access request arrives.
5. Employee opens the matter and inspects GitHub and AWS/IAM context.
6. Evidence returns to the same work context automatically.
7. Employee asks the manager for clarification.
8. Response arrives later rather than instantly.
9. Employee makes an access decision with rationale.
10. Practice Studio generates a professional access-review artifact.
11. Consequence rules update what later events are eligible.
12. Overnight activity can occur only when prior state justifies it.
13. The professional episode is reconstructed from recorded evidence.
14. Manager debrief questions are grounded in what the employee actually did.

## Required acceptance outcomes

### Sound decision path
A properly verified least-privilege decision does not manufacture a later incident.

### Weak decision path
An inadequately verified excessive grant can create monitoring attention and later signals.

This is not a branching narrative chosen by the UI. It is state-based consequence logic.
