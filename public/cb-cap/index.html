DATA & SECURITY

Trust starts with
what the data means.

CB-CAP is deidentified, place-based intelligence. No resident records. No PHI in v1. Implementation requires agreed sources, access control, and human review.

About this demonstration

The reference table uses Census 2010 ZCTA outlines for Lewis County, New York as planning lenses. These are not USPS delivery areas and not labels for people.

Sites are a seeded subset of published facilities, not a complete inventory. Digital access and trust stay Not available where no file exists. That absence is not drawn as zero.

This is not a partnership with Lewis County.
