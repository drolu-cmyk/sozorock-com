Access matters.

We aim to make the corporate and School websites usable with keyboards, screen readers and mobile devices.

Our target

WCAG 2.2 Level AA guides design and testing. This statement is not a certification of complete conformance.

Controls that help

Pages include skip links, landmarks, visible keyboard focus and labeled controls. School sculpture motion is optional, can be paused and uses a still image when reduced motion is requested.

Forms retain entered information after an error so it can be corrected. Essential program and corporate information is included in the page before JavaScript runs.

Report a barrier

Tell us the page, the task and the browser or assistive technology involved. You do not need to disclose a diagnosis. We can investigate and discuss another way to access the information.
